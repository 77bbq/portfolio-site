# 机器人作品集 QA 记录

日期：2026-10-20

范围：本地静态站点、七个项目、八张图片、两段视频、GitHub Pages 构建配置

结论：本地发布候选通过功能与可访问性验收；**公开发布仍被素材授权与隐私确认阻断**。

本次没有登录 GitHub、创建远端仓库、推送代码或生成最终二维码。二维码应在公开地址验证完成后生成。

## 自动化验证

- QA 开始前运行 `pnpm install --frozen-lockfile && pnpm verify`，冻结安装与完整验证均退出 0。
- QA 中发现封面裁切问题后，先加入会失败的输出测试，再为“智能采摘车”和“睿抗机器人”启用 `contain`；重新构建后该测试通过，并在 1440 px 浏览器中确认主体完整显示。
- 本记录加入暂存区后运行最终 `pnpm verify`：57 个单元测试、Astro 类型检查（0 errors / 0 warnings / 0 hints）、扩展性检查、8 页生产构建、40 个输出/审计测试及仓库审计全部通过。
- 使用 `pnpm preview --host 127.0.0.1 --port 4321` 启动本地预览，根路径返回 HTTP 200；浏览器检查完成后向同一进程发送 Ctrl+C，并确认进程退出。

## 交互、可访问性与网络

- 键盘顺序覆盖跳转链接、站点导航、七张项目卡、返回链接和视频控件；焦点均有 3 px 高对比轮廓。
- 跳转链接可将焦点移到 `main-content`；卡片和返回链接的交互高度为 44–48 px。
- 图片替代文本和视频可访问名称均有实际含义。两段视频有原生控件，`autoplay` 为 false，移动端 `playsinline` 有效。
- `prefers-reduced-motion: reduce` 会关闭平滑滚动，并将动画/过渡压缩到 0.01 ms。
- 最低文字对比为 `#708393` 对 `#0d151f` 的 4.68:1；主要文字 17.05:1，次要文字 7.79:1，蓝色交互文字 8.95:1，满足正常文字 WCAG AA。
- 页面资产检查只观察到本地样式、图片和视频海报；无远程字体、样式表、图标或脚本请求。静态站点审计也禁止外部运行时资源。

## 发布阻断项与已知限制

公开推送前，所有者需要明确确认：

1. 团队成员、学校/实验室、比赛主办方、摄影者和画面中人物允许公开这些图片与视频。
2. 空地协同视频左缘人物的处理方式，以及两段视频音轨是否有可公开使用的权利。
3. 电赛车二维标签的内容可以公开，或同意先做模糊处理。
4. 空地协同比赛封面中的模板/背景图形可以公开。
