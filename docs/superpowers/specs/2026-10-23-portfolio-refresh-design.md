# 个人项目作品集改版

目标：减少模板感，同时服务求职浏览与个人项目展示。用户明确选择浅色方向，保留现有 Astro、Markdown 内容集合与部署方式。

## 方向

比较了浅色工程手记和收敛装饰的深色方案。用户选择浅色；页面以自然的纸白、深色文字和少量砖红强调色呈现，重点是实物、职责和已有成果。

## 页面

- 首页介绍缩短高度，姓名、方向、个人简介和项目入口清楚分层。
- 研究生项目采用横向条目，本科项目采用两列实物图集；手机统一单列。
- 项目卡不使用包围式面板、浮动编号、光效或装饰图形。阶段、状态、动态数量与访问路径保持可用。
- 空封面改为文字式研究记录。竖图保留完整构型，不裁掉机械结构。
- 已有摘要、职责和成果展示在首页。只使用原文与证书元数据支持的信息，不推测技术栈、个人职责或性能。
- 详情页沿用一致的排版、配色与阅读宽度。

## 约束与范围

保留工作区已有改动和项目正文；重复的职责正文留待作者核实。简历、邮箱和 GitHub 未配置时继续隐藏。修复 DROID_SLAM 草稿目录与 slug 不一致的现有检查失败，使用稳定的 droid-slam 标识。

## 验证

使用已有单元测试、Astro 检查、构建、输出测试和站点审计；增加成果字段展示的针对性输出检查。检查桌面、窄屏、详情、图片和键盘焦点。此次只交付本地改动，不发布。
